# Резонансный кристалл

## Общая информация

Резонансный кристалл — редкий минерал, способный усиливать и фокусировать Синт Флюкс. Является аналогом кайбер-кристалла из оригинальной вселенной. Используется для создания фазовых клинков, питания реакторов и шифрования данных.

## Свойства

- Усиление Флюкс-энергии: кристалл может увеличить мощность техники или способностей в несколько раз.
- Фокусировка: позволяет направлять энергию в узкий луч или создавать защитные поля.
- Совместимость: работает только с устройствами, настроенными на Синт Флюкс.

## Применение

- Фазовые клинки: кристалл служит ядром клинка, определяя его цвет и характеристики.
- Реакторы: используется в качестве основного источника энергии для малых кораблей и станций.
- Шифрование: кристаллы применяются для создания защищённых каналов связи.

## Добыча и контроль

- Основные месторождения: Синдерфелл, Амберлин, Келтор.
- Контроль Доминиона: добыча строго регулируется, кристаллы считаются стратегическим ресурсом.
- Чёрный рынок: контрабандисты поставляют кристаллы Вангард Пакту для создания оружия и техники.

## Легенды

Существует легенда, что первый резонансный кристалл был найден на Майрфолле древними Люминариями. Они использовали его для создания первого Флюкс-архива.
